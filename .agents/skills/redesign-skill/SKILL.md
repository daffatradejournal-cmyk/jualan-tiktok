# Redesign Skill (Audit & Polish)

Framework for auditing and redesigning existing web pages with surgical precision.

---

## 1. The 4-Phase Redesign Audit

1. **Information Architecture & Hierarchy Audit**:
   - What is the single primary action the user must take?
   - Is that action clearly visible in the first viewport (above the fold) without scrolling?
   - Are secondary actions competing with primary conversions?

2. **Visual Clutter & Slop Elimination**:
   - Identify overused gradient fills, low-contrast text, unnecessary decorative borders, and repetitive icon boxes.
   - Replace generic stock elements with authentic product screenshots, process flows, or clear benefit lists.

3. **Mobile & Ergonomic Verification**:
   - Test sticky bottom CTAs (e.g., WhatsApp button) for thumb-friendly tapping.
   - Ensure sticky elements do not obscure legal disclaimers, modals, or essential content.
   - Verify tap targets adhere to minimum 44px height.

4. **Conversion Friction Reduction**:
   - Make pricing structures crystal clear.
   - Highlight guarantees (e.g., "Garansi Uang Kembali / Panduan Sampai Bisa").
   - Simplify contact flows (one-click pre-filled WhatsApp link with clear message intent).
