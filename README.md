# Landing Page Jasa NPWP & WPS PC Level (v4 - Promo Diskon & Multi-WhatsApp)

Website landing page responsif, estetik, dengan efek diskon harga coret dan nomor WhatsApp terpisah untuk masing-masing produk. Siap deploy langsung ke Netlify.

## Update Versi 4:
1. **Fitur Promo & Harga Coret (Strike-through)**:
   - **Jasa Pembuatan NPWP**: ~Rp120.000~ menjadi **Rp80.000** (Diskon 33% / Hemat Rp40.000).
   - **WPS PC Level**: ~Rp85.000~ menjadi **Rp60.000** (Diskon 29% / Hemat Rp25.000).
   - Terdapat badge diskon animasi di atas gambar produk, harga coret di kartu, serta rincian hemat di dalam jendela mengambang (modal).
2. **Pemisahan Nomor WhatsApp Masing-Masing Layanan**:
   - **NPWP**: Mengarah ke WhatsApp `085121342871` dengan pesan otomatis:
     > *"Halo, saya ingin pemesanan npwp"*
   - **WPS PC Level**: Mengarah ke WhatsApp `082392048485` dengan pesan otomatis:
     > *"Halo, saya ingin pemasangan wps pc level"*
3. **Jendela Mengambang (Modal Popup)**:
   - Menampilkan harga promo, badge hemat, foto, deskripsi, serta spesifikasi detail.
4. **Deploy Siap Pakai di Netlify**:
   - Pure HTML, CSS, JavaScript tanpa dependencies tambahan.

## Cara Deploy ke Netlify:
1. Ekstrak file `landing-page-npwp-wps-v4.zip`.
2. Buka [app.netlify.com](https://app.netlify.com).
3. Drag & drop folder hasil ekstrak ke dashboard Netlify.
